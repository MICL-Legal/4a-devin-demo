例子 1　·　共 5 個

業務報價系統

隔離衣 Level 4

過去要嘛排隊等 IT，要嘛自己在 Excel 拉公式對半天，還常常算錯。現在你只要把「要什麼」講清楚——AI 直接長出一個能操作的報價介面，輸入數量，運費、稅金自動帶進去。

把整段複製，貼給 Claude Code：

現場用的那一句話
我要一個業務報價系統產品是隔離衣等級4
運費税金請先幫我
拉一個
操作介面 可以輸入 數量
✓ 成功長這樣瀏覽器跑出一個報價畫面，輸入數量就自動算出金額（含運費、稅金）＝ 成功。
💡 換成你的把「隔離衣等級4」改成你自己部門的產品，其他照抄——這就是你今天帶回去的第一塊。
例子 2　·　共 5 個

一句話影片機

MoneyPrinterTurbo · 站在巨人肩膀上

你不用自己寫程式——GitHub 上已經有人做好一台「影片機」。你只要跟 Claude 說「下載到哪、幫我跑起來」，它把環境裝好、網頁打開。這就是借力：借別人做好的成品（Billy 場會深講怎麼找、怎麼確認不是釣魚坑）。完整手把手在 2-4。

把整段複製，貼給 Claude Code：

現場用的那一句話
https://github.com/harry0703/MoneyPrinterTurbo下載到
電腦路徑C:\AI-Workspace\Claude\Project\002-MPT  網頁開啟
✓ 成功長這樣它自己把專案抓下來、裝好環境，最後瀏覽器開出影片機的操作網頁＝ 成功。
📁 資料夾這句話裡的 002-MPT 是一個要先存在的資料夾——在例子 3 的 Step 1 會一次建好四個，建過就不用再建。
⏳ 要等這支要下載的東西比較多，跑幾分鐘是正常的——畫面一直跳字就是還在做，不要關掉。
例子 3　·　共 5 個

飲料店訂購網頁

現場 live demo（2-2）· 這一個全員親手做

一句話，當場長出一個能點餐、能記單的小系統：點品項 → 跳出視窗輸入名字 → 送出 → 看得到目前每個品項各賣了幾杯。那張你看得懂的表，就是它的「資料庫」——下週 Billy 場再教你把它搬進真正的資料庫。
STEP 1先把工作資料夾建好只做一次，後面每一場都用同一個
為什麼AI 要幫你動手，得先知道去哪動手。全班用同一個路徑，卡住的時候講師一眼就知道你的東西在哪；各建各的，講師要一台一台幫你找。

① 按鍵盤 Win + R —— 螢幕左下角會跳出一個小視窗（叫「執行」）。

② 把這個貼進去、按 Enter —— 檔案總管會直接開在 C 槽，不用自己找：

貼進「執行」小視窗
C:\

③ 在白色空白處按滑鼠右鍵 → 新增 → 資料夾，把名字改成 AI-Workspace。

④ 按兩下進去 AI-Workspace，同樣方式再建一個 Claude。

⑤ 按兩下進去 Claude，再建一個 Project。

⑥ 按兩下進去 Project，在裡面建四個資料夾。名字點一下就複製，不用自己打：

⑦ 建完長這樣：

C:\AI-Workspace\Claude\Project\ 001-Demo\ ← 飲料店 Demo（這一堂要用） 002-MPT\ ← MoneyPrinterTurbo（例子 2） 003-notebooklm\ ← NotebookLM Credential\ ← 金鑰

⑧ 確認你建對了：再按一次 Win + R，貼上這一整行按 Enter：

確認用 · 貼進「執行」小視窗
C:\AI-Workspace\Claude\Project
✓ 這一步成功長這樣視窗打開後看得到那四個資料夾＝ 建對了。跳出「找不到」＝ 名字打錯或建錯層，現在改比後面才發現輕鬆十倍。
按 Win + R 沒反應？（備援作法）
有些公司電腦會把「執行」關掉。改走這條：
按 Win + E 打開檔案總管 → 點左邊的「本機」（有些電腦寫「這台電腦」）→ 按兩下「本機磁碟 (C:)」→ 接著回到上面第 ③ 步繼續。
打資料夾名字最容易錯的三件事
① 中文輸入法沒關。打出來的會是全形的 ００１－Ｄｅｍｏ，看起來很像但電腦當成完全不同的字。打名字前先按一下 Shift 切回英文。（所以建議直接用上面的複製鈕。）
② 連字號打成底線或空白。是 001-Demo（減號），不是 001_Demo、也不是 001 Demo。
③ 建錯層。四個資料夾要在 Project 裡面，不是跟 Project 並排。第 ⑧ 步的確認就是在抓這個。
STEP 2讓 Claude Code 到那個資料夾你在哪裡啟動它，它就只認得那裡

① 按 Win + R，輸入 powershell，按 Enter。

② 貼這一整行、按 Enter —— 告訴它「到飲料店這個資料夾工作」：

貼進 PowerShell
cd C:\AI-Workspace\Claude\Project\001-Demo

左邊那串字要變成 PS C:\AI-Workspace\Claude\Project\001-Demo> 才對。

③ 啟動 Claude Code：

貼進 PowerShell
claude
✓ 這一步成功長這樣進到 Claude Code 的對話畫面，可以打字了 ＝ 可以往下走。
STEP 3把整段複製，貼給 Claude Code
現場用的那一句話
C:\AI-Workspace\Claude\Project\001-DEMO 請幫我做一個飲料店,訂購網頁有幾個熱門的品項,直接購買彈跳視窗輸入名字，送出後可以看到訂單料表 目前個別品項購買數量多少,
⚠️ 大小寫這句話裡寫的是 001-DEMO，你建的是 001-Demo——Windows 不分大小寫，這是同一個資料夾。不用改、也不用重建。
✓ 成功長這樣網頁能下單，而且下完單看得到每個品項的累計數量＝ 成功。
💡 換成你的把「飲料店」換成你部門真的在收的東西（報修單、領料單、訂便當），句型完全一樣。
